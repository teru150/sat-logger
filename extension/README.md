# SAT ロガー（Chrome 拡張）

Question Bank・Ascent の問題と MyPractice の模試結果を記録します。
問題番号・正誤・答え・本文・選択肢・解説など、画面から取得できる項目を保存します。

1. https://teru.page/sat で名前・パスワード・招待コードを入力して登録します。
2. 登録後に表示される拡張用の合言葉を控えます。ほかの人には渡さないでください。
3. ZIP を展開し、Chrome の「拡張機能」→「デベロッパーモード」→「パッケージ化されていない拡張機能を読み込む」で展開先を選びます。
4. 拡張の「設定」に URL `https://teru.page` と合言葉を貼って保存します。

- Question Bank：問題を開き正解・解説を表示すると、右下に記録ボタンが出ます。
- Ascent：解いた後の見直し画面に記録用の帯が出ます。
- MyPractice：「Details」の「この模試を全部記録」で正誤と各問の本文・答えを取り込みます。
- 記録は自分のアカウントの領域にだけ保存・表示され、他の利用者の記録とは混ざりません。
- 写真・画面全体の保存は一般利用者にはまだ対応していません。
- 困った時は https://teru.page/sat にログインして一覧を確認してください。
- 合言葉を失くした場合は、一覧ページの下部で新しい合言葉を作り設定に貼り直してください。
