# SAT ロガー(Chrome の拡張機能、v1)

Ascent(`climb.ascenttestprep.com`)や College Board の Question Bank で問題を解いた記録を、
**1 問ずつ自動で teru.page の SAT 問題ログ(シート)に書く**小さな拡張機能です。
読み取れなかった時のために、「画面をそのまま teru.page に保存する」ボタンも残してあります(v0 の機能)。

## 入れ方(Linux でも学校の Mac でも同じ、最初に 1 回)

1. zip を展開して、できたフォルダを消さない場所に置く。**そのフォルダを開いた時に、`manifest.json` が直に見えれば正しい**フォルダです(フォルダの中にもう 1 つフォルダがある形なら、`manifest.json` がある方の中のフォルダを選ぶ)。
2. Chrome のアドレス欄に `chrome://extensions` と打って開く。
3. 右上の「**デベロッパー モード**」を入れる。
4. 左上の「**パッケージ化されていない拡張機能を読み込む**」を押し、**`manifest.json` が直に見えるフォルダ**を選ぶ。
   (「マニフェスト ファイルが見つかりません」と出たら、1 つ内側か外側のフォルダを選び直す。)
5. 一覧に「SAT ロガー」が出れば完了。ツールバーのパズルのアイコンから、ピン留めしておくと押しやすい。

> 学校の Mac は管理されていて、拡張機能を読み込めないことがあります。「デベロッパー モード」が灰色で入れられない時は、
> Mac では今までどおり `teru.page/app/sat` に手で入力してください(拡張機能は Linux だけで使う)。

## 合言葉を貼る(最初に 1 回)

1. ブラウザで teru.page にログインして、`/app/sat` を開き、**一番下の「拡張機能の合言葉」**へ行く。
2. 「使う PC の名前」(例: Linux、学校の Mac)を入れて「合言葉を作る」を押す。
3. `satx_` で始まる合言葉が出る(**この時 1 回しか表示されません**)。「コピー」を押す。
4. Chrome のツールバーで「SAT ロガー」のアイコンを押し、「設定」を開いて「合言葉」の欄に貼り、「保存」を押す。
   teru.page の URL の欄は `https://teru.page` のままでよい。

合言葉をなくした・人に見せてしまった時は、同じ場所の「取り消す」を押して、作り直してください。
取り消すと、その PC の拡張機能はその場で送れなくなります。合言葉は teru.page の他のページには効きません。

## 使い方(v1: 自動で記録します)

**押す物はほぼありません。ふだんどおり問題を解いてください。**

### Ascent

1. 問題を解いて、**見直し画面**(「Correct Answer」と「Your Answer」の印が出る画面)を開く。
2. 開いたとたんに、その 1 問が自動で SAT 問題ログに記録されます。右下に「**記録した(Ascent Q1 誤)**」と出ます。
   記録されるもの: 問題番号、難しさ、かかった時間(Ascent の表示のまま)、分野、小分野、正解、自分の答え、正誤、本文、設問、選択肢、解説。
3. 同じ見直し画面をもう一度開いても、**2 回は記録しません**(「同じ問題は記録済みでした」と出ます)。

### Question Bank(College Board)

1. 問題の一覧から問題を 1 つ開く(ダイアログが開いた時刻から、時間を計り始めます)。
2. 解く。答えを見る時に「**Show correct answer and explanation**」を押す(押すまでの時間が、かかった秒になります)。
3. 右下の帯に「**選んだ答え: A B C D**」と「秒」「記録」が出ます。**自分が選んだ答えを押す**と、秒が入っていれば**その場で自動で記録**されます(「記録」を押す必要はありません)。
   (自分がどれを選んだかは画面から分からないので、ここだけ手で押します。秒は自動で入ります。)
   間違えて押した時は、teru.page の `/app/sat` の一覧から取り消せます。
4. **問題の窓を閉じても、右下の帯は残ります**(10 分まで、次の問題を開くまで)。閉じた後でも、選んだ答えを押せば記録されます。
   解説を開かないまま閉じた時は、帯に「正解も」の行が出るので、正解も押してください(秒は、開いてから閉じるまでになります)。
   ただし、開いて答えを選ばずに **5 秒以内**に閉じた時は、まちがえて開いたとみなして帯を消します。
5. 先に解説を開いていた時は時間が測れないので、「秒」の欄が空になります。そのときは秒を手で入れて、選んだ答えを押し、「記録」を押してください(秒が空の間は自動では記録されません)。

### 間違えた問題の「間違いの型」

自動で記録した誤答は、間違いの型がまだ空です。teru.page の `/app/sat` の一覧で、**「型が未記入」の赤い問題**を開くと、
その場で型を選べます(選ぶとシートにも書かれます)。正解した問題には型は要りません。

### 「画面を保存」ボタンは記録ではありません

右下の「**画面を保存**」と、アイコンの「今の画面を保存(予備)」は、**SAT 問題ログには書きません**(画面を teru.page の中に保存するだけの予備です)。
問題を 1 問記録したい時は、上の手順(Ascent は見直し画面を開く、Question Bank は問題を開いて解説を出し、選んだ答えと「記録」を押す)にしてください。
「保存した」と出ても、問題ログには増えません。

### うまく読めなかった時

画面の作りが変わって読めなかった時は、右下に「**読めなかった(読めなかった所: …)**」と出ます。
その時は、右下の「**画面を保存**」ボタン(または、ツールバーのアイコン →「今の画面を保存(予備)」)で画面をそのまま保存してください。
送った画面は teru.page の中の `data/sat/captures/` に保存されるので、そこから読み取りを直します。

| 出る言葉 | 意味と直し方 |
|---|---|
| 合言葉が未設定です | アイコン → 設定 → 合言葉を貼って保存 |
| 合言葉が違うか、取り消されています | teru.page の `/app/sat` で新しい合言葉を作って貼り直す |
| 記録できなかった(…混雑…) | Google のシートが混んでいます。少し待って、見直し画面を開き直す(Question Bank は「記録」をもう一度) |
| 大きすぎます(送る画面の時) | 1 回 2 MB まで。ページを開き直して、問題だけが出ている状態で押す |
| 送りすぎです | 1 分に 30 回まで。少し待つ |
| つながりませんでした | ネットを確かめる。teru.page の URL が `https://` で始まっているか確かめる |

## 中身について(知っておくこと)

- **自動で送るもの**: 見直し画面(Ascent)や、記録を押した問題(Question Bank)の、問題文・選択肢・正解・解説・時間などの 1 問ぶんだけ。
  ページ全体や、名前の入る画面の部分は送りません。
- **「画面を保存」ボタン(予備)で保存するもの**: 今のページの本文の部分の HTML と文字、URL、題名、送った時刻。
  Ascent の画面には右上に Teru の名前などが入ります。保存先はこの PC の中(`data/sat/captures/`)だけで、GitHub には入りません。
  こちらは押した時だけ送ります。
- teru.page 以外には送りません(URL の欄を別の場所に変えた時は、Chrome が許可を聞いてきます)。

## 直した時(更新)

- Linux: `chrome://extensions` で「SAT ロガー」の丸い矢印(更新)を押す。
- 学校の Mac: 新しい zip を置き直して展開し、同じ手順で読み込み直す。

## 作った人向けのメモ

- 受け口: `teru_site/satext.py`(POST `/app/sat/capture`、合言葉は SHA-256 の要約値だけを `teru_site/.runtime/sat_ext.sqlite3` に保存)。
- 設計: `docs/plans/sat-chrome-ext-20260930.md`。Ascent のホストは `climb.ascenttestprep.com`(Teru 確認済み)。`manifest.json` の
  `content_scripts.matches` に余分な候補(`*.ascenttestprep.com`、`*.mentomind.com`)も残してある。
- 読み取りの部品は `parse.js`(本物の画面の HTML `data/sat/page-samples/ascent-review.html`、`qb-results.html` で確かめてある。
  テストは `tests/test_sat_chrome_ext.py`、jsdom で同じ関数と content.js を通す)。画面の作りが変わったら、新しい HTML を
  `data/sat/captures/` から見本にして、`parse.js` の選択子を直す。
- 記録は POST `/app/sat/log`(合言葉で受ける)。同じ問題は サーバーが 問題番号 + 日付 + 本文の頭 50 字 で断る。

## 経過秒と目標秒(0.4.3)

Question Bank の帯に「経過 N 秒」が 1 秒ごとに出ます(問題の窓が開いた時から。解説が出ると止まり、記録する秒と同じ値になります)。
「目標」の欄に秒を入れておくと、経過が目標を超えた時に経過の文字が赤く、目標より 30 秒超えた時に帯の背景が赤くなります(音は出ません)。目標は問題の型(Skill)から自動で入ります(Words in Context 35 / Text Structure 60 / Cross-Text 75 / Central Ideas 60 / Command of Evidence 90 / Inferences 75 / Boundaries 30 / Form Structure Sense 45 / Transitions 45 / Rhetorical Synthesis 60、読めない時 60)。欄を手で変えると、その型の目標として覚えて、次からそちらを使います(欄の横に「型の既定」か「自分の設定」と出ます。空にすると既定に戻ります)。
Ascent は、問題を解いている画面の作りが分からないため、まだ経過秒は出ません(見直し画面の秒を読む今までの記録はそのままです)。
# MyPractice の一括記録 (0.5.3・一覧のみの最小版)

拡張機能を読み込み直し、MyPractice の Details ページを再読込して「この模試を全部記録」を押す。
フィルターは解除する。行の一覧だけから送る。Review は開かずページの操作もしない。完了までページを切り替えない。
既存の合言葉で同じ /app/sat/log に送り、実施日・Practice・セクション・モジュール・問題番号で重複を避ける。
全問(100問まで)を1回のPOSTで送り、受け口が既存のID・日付・問題番号をまとめて確認し、未登録の行だけを1回のSheets追記で保存する。送信後の通信エラー時も再度押せる。既に登録した問題は増やさない。
問題番号・セクション・モジュール・正誤・実施日・模試番号と、一覧にある分野だけを送る。画面にない本文・小分野・答え・秒は空欄のまま、分類の自動推測もしない。Review の本文収集は第2段階として保留。
セクションとモジュールは問題番号とメモにも保存する。Math の数値回答は現行ログの A〜D 欄に入れない。
保存された P9 HTML の実測は **RW 54問・正48誤6**。集計カードも同じで、58問・正51誤7ではない。
この保存HTMLにはMath行がなく、非表示のReview本文は1問分だけ。実際のChromeで全問の本文が読めるかは本人の操作で確認する。

# 本文の強調 (0.5.2)

今後記録するQB・Ascentの本文では下線を `__…__`、太字を `**…**`、斜体を `*…*` として保存する。
HTMLタグ、inline style、下線のクラスとページCSSを読み、同じ強調の入れ子は二重に囲まない。既存ログは変更しない。

# Review の詳細取り込み (0.6.0)

最初に「この模試を全部記録」で一覧を登録し、その後「答えと本文も取り込む」を押す。
Review が順に開くので、完了までページのボタンを押さない。MutationObserver で対象の問題と答えの描画を待ち、本文・設問・選択肢・自分の答え・正解・解説を読む。
最後に1回だけ送信し、既存の同じ日付・問題番号の行で空のセルだけを埋める。既存の文章、答え、間違いの型は変更しない。未登録の問題は新規作成しない。
読めなかった問題数と実際の経過秒を表示する。Math の数値回答も I/J 列に文字列で保存する。98問の3分以内は実機測定が必要。

## 0.6.1: 1ボタンで一覧から詳細まで

「この模試を全部記録」で Show Correct Answers を自動でONにし、一覧登録→Reviewの詳細取り込みまで続ける。ボタン横に n/全問 の進捗を出す。
ONにできなければ「Show correct answers を ON にして押し直して」と表示して停止する。ONにしたトグルは戻さない。
一覧が既にある場合の再取り込みには「本文だけ取り直す」も使える。どちらも空欄だけの補充で、既存の答えや間違いの型は変更しない。

## 0.6.2: Math の数式の修復

MathMLの分数は `5/32` / `(x+1)/(x-1)`、指数は `x^2`、添字は `a_1`、平方根は `√(x)`、累乗根は `root(x,3)`、表は行ごとの改行で保存する。MathJaxのSVGと補助MathMLは重複させない。電卓UIは本文から除く。
「本文だけ取り直す」では、出どころがBluebook模試で番号がMathの行に限り、取得した本文・設問・選択肢・解説・答えの列を上書きできる。RWは従来どおり空欄のみ。間違いの型・日付・ID・メモなどは上書きしない。変更前のセル値はシート監査ログに控える。
